# Full Stack Development Capstone – Car Dealership Reviews

## Repository
romansaravana619-lang/devops-capstone-project

## Project Name
Best Cars Dealership Review Portal

## Overview
A full-stack Django and React application for browsing car dealerships, viewing dealer reviews, registering and logging in users, filtering dealers by state, and submitting reviews.

## Technologies
Django, React, Node.js/Express, MongoDB, SQLite, Docker, GitHub Actions and Kubernetes.

## Main API endpoints
- /djangoapp/get_dealers
- /djangoapp/get_dealers/<state>
- /djangoapp/dealer/<id>
- /djangoapp/review/dealer/<id>
- /djangoapp/get_cars
- /djangoapp/login
- /djangoapp/logout
- /djangoapp/register
- /djangoapp/add_review
