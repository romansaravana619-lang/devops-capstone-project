![Build Status](https://github.com/romansaravana619-lang/devops-capstone-project/actions/workflows/ci-build.yaml/badge.svg)

## Overview

This repository contains the planning artifacts for a DevOps capstone project using Agile user stories, a product backlog, labels, and a Kanban workflow.

## Project Planning

The project is organized around user stories that describe the required functionality from a user's perspective. The stories are tracked through GitHub Issues and organized using a Kanban-style workflow.

## Repository Artifacts

- `README.md` — project overview and planning information.
- `user-story.md` — project user stories and acceptance criteria.

## Agile Workflow

The planned workflow is:

**New → In Progress → Review → Done**

Issues are used to track individual user stories, while labels are used to categorize work.
